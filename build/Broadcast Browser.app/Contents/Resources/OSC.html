Broadcast Browser OSC Reference

Broadcast Browser can be controlled with OSC (Open Sound Control), and it reports its status as OSC. With this you can start and stop a broadcast from a Stream Deck (through Bitfocus Companion), QLab, TouchOSC, a lighting desk, or your own scripts, and you can check from anywhere that every tab and output is healthy.

  • Input (commands): UDP port 9300 by default. Set it in

Preferences › OSC › Input port.

  • Output (feedback): sent to 127.0.0.1:9301 by default. Set it in

Preferences › OSC › Feedback output.

Every address starts with **/bb/**.

1. Transport

ProtocolOSC 1.0 over UDP, IPv4
Input port9300 by default; any free port from 1024 to 65535
Feedback destination127.0.0.1:9301 by default; any host name or IPv4 address, including broadcast addresses
Feedback ratea full status snapshot every 1 s by default (250 ms – 5 s), plus immediate events when something changes
Packetsone message per UDP packet by default. Optional: OSC bundles of up to 1400 bytes each, time tag 1 ("immediately")
Encodingbig-endian, 4-byte aligned, as defined by the OSC 1.0 specification

Port check. When you apply a new input port, the app first tries to bind it. If another application already owns the port, the app says so and does not switch, so pick a different port. If the saved port is taken at launch, the status bar shows OSC off and Preferences explains why.

Security. OSC has no authentication. On a shared network, fill in Accept from: a comma-separated list of IP addresses that may send commands (localhost is accepted for 127.0.0.1). Packets from any other address are counted as Rejected and ignored. The /js and /css commands are disabled unless you turn on Allow /js and /css commands.

True/false values in feedback

Pick the style in Preferences › OSC › True/false values:

SettingisLive = true is sent asisLive = false is sent as
OSC true/false (default)type tag Ttype tag F
Integer 1/0i 1i 0
Strings "true"s "false"

Some receivers ignore OSC T/F arguments. If yours shows no value for isLive, choose Integer 1/0.

True/false values in commands

Any argument that means true/false accepts:

  • T, F
  • integers or floats (0 = false, anything else = true)
  • the strings true, false, on, off, yes, no, 1, 0

3. Addressing tabs and outputs

Wherever this reference writes **{tab}**, you can use any of these:

FormExampleMeaning
Position/bb/tab/2/goLiveThe 2nd tab from the left (1-based)
selected/bb/tab/selected/reloadThe tab currently shown in the main window
Tab ID/bb/tab/7F2C…-E91A/stopThe tab's UUID, which never changes. Read it from /bb/tab/{n}/id
Tab name/bb/tab/Scoreboard/goLiveThe tab name (from Page › Name, or the page title). Not case-sensitive; write spaces as _, e.g. Main_Scoreboard

Wherever this reference writes **{output}**, you can use:

  • a position: the 1-based order in that tab's Outputs panel
  • the output's UUID
  • the output's name, with spaces written as _

Positions change when you reorder, add or close tabs. The app sends /bb/event/tabsChanged whenever that happens. For permanent mappings, use tab names or IDs.

6. Decoding OSC by hand

An OSC message has three parts:

  1. Address. An ASCII string ending in a null byte (00), padded with more nulls to a multiple of 4 bytes.
  2. Type tags. A string that starts with , followed by one letter per argument, ending in a null byte and padded to a multiple of 4 bytes.
  3. Arguments, in order:
  4. i: 4 bytes, big-endian integer
  5. f: 4 bytes, big-endian float
  6. s: string, null-terminated and padded to 4 bytes
  7. T / F: no bytes

**Example 1: /bb/tab/1/isLive T**, 24 bytes in total:

2f 62 62 2f 74 61 62 2f 31 2f 69 73 4c 69 76 65   "/bb/tab/1/isLive"  (16 bytes)
00 00 00 00                                       null + padding
2c 54 00 00                                       ",T" + null + padding

**Example 2: /bb/session/uptime 12.5**, 28 bytes in total:

2f 62 62 2f 73 65 73 73 69 6f 6e 2f 75 70 74 69 6d 65 00 00   "/bb/session/uptime" + null + padding (20 bytes)
2c 66 00 00                                                   ",f" + null + padding
41 48 00 00                                                   12.5 as a big-endian float

Bundles. These are only sent if you turn on Pack messages into OSC bundles. A bundle starts with the string #bundle plus a null byte (8 bytes), then an 8-byte time tag, which is always 00 00 00 00 00 00 00 01. Then come the elements, each written as a 4-byte big-endian length followed by that many bytes of message.

A complete decoder in Python (no libraries needed)

import socket, struct

def read_string(data, i):
    end = data.index(b"\0", i)
    text = data[i:end].decode("utf-8")
    return text, (end + 4) & ~3          # skip padding to the next multiple of 4

def decode(data):
    """Returns a list of (address, [arguments])."""
    if data.startswith(b"#bundle\0"):
        messages, i = [], 16
        while i + 4 <= len(data):
            size = struct.unpack(">i", data[i:i + 4])[0]
            messages += decode(data[i + 4:i + 4 + size])
            i += 4 + size
        return messages
    address, i = read_string(data, 0)
    tags, i = read_string(data, i)
    args = []
    for tag in tags[1:]:
        if tag == "i":   args.append(struct.unpack(">i", data[i:i + 4])[0]); i += 4
        elif tag == "f": args.append(struct.unpack(">f", data[i:i + 4])[0]); i += 4
        elif tag == "s": text, i = read_string(data, i); args.append(text)
        elif tag == "T": args.append(True)
        elif tag == "F": args.append(False)
    return [(address, args)]

sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
sock.bind(("0.0.0.0", 9301))
while True:
    packet, sender = sock.recvfrom(65536)
    for address, args in decode(packet):
        if address.endswith("/isLive") or address.startswith("/bb/event"):
            print(address, args)

Sending a command with no libraries

import socket

def osc(address, *args):
    def pad(b): return b + b"\0" * (4 - len(b) % 4)
    tags, payload = ",", b""
    for a in args:
        if isinstance(a, bool):  tags += "T" if a else "F"
        elif isinstance(a, int): tags += "i"; payload += a.to_bytes(4, "big", signed=True)
        elif isinstance(a, float):
            import struct; tags += "f"; payload += struct.pack(">f", a)
        else: tags += "s"; payload += pad(str(a).encode())
    return pad(address.encode()) + pad(tags.encode()) + payload

s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
s.sendto(osc("/bb/tab/1/goLive"), ("127.0.0.1", 9300))
s.sendto(osc("/bb/tab/Scoreboard/zoom", 1.25), ("127.0.0.1", 9300))

7. Recipes

Bitfocus Companion / Stream Deck

  1. Add the Generic: OSC connection. Target host = the IP of the Mac running Broadcast Browser (127.0.0.1 if Companion runs on the same Mac). Target port = 9300.
  2. To go live: a button with Send message without arguments → /bb/session/goLive.
  3. To toggle one tab: /bb/tab/1/toggle, or /bb/tab/Scoreboard/toggle by name.
  4. For feedback (a button that lights up when the tab is live), point Preferences › OSC › Feedback output at Companion's OSC listening port, or have Companion send /bb/feedback/subscribe i:<its port> once at startup. Then use /bb/tab/1/isLive in your button feedback or variables. If Companion doesn't react to T/F values, set True/false values to Integer 1/0.

QLab

Use a Network cue with an OSC message, destination <Mac IP>:9300, e.g. /bb/tab/2/goLive or /bb/tab/2/rule/3/enabled 1.

Watchdog

Check two things on the receiving end:

  • Is /bb/heartbeat still increasing? If it stops for more than

3 × your feedback interval, alarm.

  • Is /bb/session/outputsError above 0? If so, alarm.

For each tab that should be on air, also watch /bb/tab/{n}/isLive.

8. Changes to this interface

Addresses are stable within a major version. New messages may be added to the snapshot at any time, so receivers should ignore addresses they don't know.
